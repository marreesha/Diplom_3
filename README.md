## Установка

1. Установка зависимостей:

```bash
pip install -r requirements.txt
```

2. Запуск теста:

```bash
pytest
```

3. Генерация отчета о тестировании:

```bash
allure generate allure_results --clean -o allure_report
```

4. Просмотр отчета:

```bash
allure open allure_report
```
